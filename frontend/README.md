# Sachin King Photo Frame - Frontend

This is the React + Vite + Tailwind CSS frontend application.

## How to run locally:

1. Open terminal and navigate to the frontend folder:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Make sure the backend server is running on `http://localhost:5000`.

4. Start the frontend development server:
   ```bash
   npm run dev
   ```

The application will open on `http://localhost:3000`. API requests to `/api/*` will automatically proxy to the backend at `http://localhost:5000`.
